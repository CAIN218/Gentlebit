プライバシーポリシー

最終更新日: 2026年10月16日

Gentlebit（個人開発者 Yuga Tanaka が運営する本サイト）と、本サイトで公開しているアプリにおける情報の取り扱いについて説明します。

1. 取得する情報

お問い合わせフォーム。フォームからご連絡いただいた場合、入力された名前・メールアドレス・メッセージを受け取ります。内容の確認と返信のためだけに使い、それ以外の目的で第三者に提供することはありません。

アクセス解析・Cookie。本サイトはアクセス解析ツールや広告を使用しておらず、Cookieも設定していません。変更する場合は、先に本ポリシーを更新します。

アプリ。本サイトのアプリはお使いの端末上で動作し、開発者がアプリを通じて個人情報を収集することはありません。設定は端末内のファイルにのみ保存されます。AudioSwitcherとLuminaは、新しいバージョンの有無を確認し、更新を選んだとき（または自動アップデートを有効にしたとき）にダウンロードするためGitHubへ接続します。このときIPアドレスなどの技術情報がGitHubに記録されることがあります（後述）。MeatCamはカメラの映像を端末内で解析するためだけに使い、通信機能はありません。

2. 利用しているサービス

  • Formspree：お問い合わせフォームの送信内容を受け取り、配信します（Formspreeのプライバシーポリシー）。
  • GitHub Pages：本サイトを配信しており、アクセス時にIPアドレスなどの技術情報がGitHubに記録されることがあります（GitHubのプライバシー声明）。
  • Google Fonts：本サイトのWebフォントを配信しており、お使いのブラウザがGoogleに直接フォントを要求します（Googleのプライバシーポリシー）。

3. ブラウザに保存されるデータ

戻るボタンで元の位置に戻れるよう、現在のタブに限ってスクロール位置を記憶します。この情報はブラウザ内にとどまり、当方には送信されません。

4. 第三者への提供

個人情報を販売することはありません。サイトの運営に必要な範囲で上記のサービスに渡す場合と、法令に基づく場合を除き、第三者に提供しません。

5. 情報の訂正・削除

送信したメッセージの訂正や削除をご希望の場合は、お問い合わせフォームからご連絡ください。

6. 改定

本ポリシーは必要に応じて改定することがあります。最新版は常にこのページに、上記の日付とともに掲載します。

7. お問い合わせ

本ポリシーに関するご質問は、お問い合わせフォームからお送りください。
