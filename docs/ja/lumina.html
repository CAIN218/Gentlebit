Lumina

複数モニターの明るさを、タスクバーからまとめて調整

OverviewFeaturesWhat's included

Luminaは、DDC/CIに対応したモニターの明るさをタスクバーから調整できるWindows常駐アプリです。通知領域のアイコンをクリックすると、接続中のモニターごとにスライダーが並んだパネルが開きます。コントロールパネルを開いたり、モニター本体のボタンを押したりする手間がなくなります。

すっきりしたスライダーパネル

通知領域のアイコンをクリックすると、モニターごとのスライダーが並んだパネルがフェードしながら表示されます。角の丸いパネルや、ドラッグ中につまみがほのかに光る演出、Gentlebit のほかのアプリとそろえた落ち着いたダークデザインなど、見た目にもこだわりました。

自動でアップデート

GitHub で新しいバージョンが公開されると通知でお知らせします。ワンクリックで更新でき、右クリックメニューで「自動アップデート」をオンにすれば自動で更新されます。「更新内容」で変更点を確認でき、メニューには今のバージョンも表示されます。

個別にも、まとめても調整できる

各スライダーはそれぞれのモニターを個別に調整します。右クリックメニューで「一斉に動かせるようにする」をオンにすると、全モニターをまとめて動かせるマスタースライダーが追加されます。

反応の遅いモニターでも操作は軽快

DDC/CIの通信は1回で最大100ミリ秒ほどかかることがあります。Luminaは各モニターの最新の目標値だけを保持して別スレッドで書き込むため、スライダーの動きが遅れません。

いつでも見えるトレイアイコン

タスクバーの明るさに合わせて、アイコンが明るい版と暗い版に自動で切り替わります。白いタスクバーでもアイコンが溶け込んで見えなくなることはありません。Windows のライト／ダークを切り替えても、すぐに追従します。

英語と日本語に対応

右クリックメニューの「Language / 言語」から表示言語を選べます。初期設定は英語です。

What's included

  • Lumina.exe — アプリ本体です。これ1つで動作し、ほかのソフトのインストールは不要です。
  • README.md — 使い方と、各メニュー項目の説明です（英語）。
Windows SmartScreenの警告について
