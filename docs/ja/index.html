    身近な「ちょっと不便」を、小さなアプリで解消する。

    Gentlebitは、身近にある「ちょっと不便」を解消するために、個人でアプリを開発しているサイトです。

    音声の出力先の切り替えやモニターの明るさ調整など、自分が日々困っていたことをきっかけに作っています。ソースコードはすべてGitHubで公開しています。

    GitHubでコードを見る

    作っている人
    Yuga Tanaka（個人）
    通信について
    AudioSwitcher と Lumina は、新しい版の確認とダウンロードのためにGitHubへ接続します。設定はお使いのパソコンの中にだけ保存されます。MeatCam は通信しません。
    署名について
    アプリにはコード署名がないため、初回起動時にWindowsの警告（SmartScreen）が出ることがあります。気になる場合は、GitHubのソースコードを先に確認できます。
