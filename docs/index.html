    About

    Small apps that fix the little annoyances of everyday life.

    Gentlebit is where I build small apps to fix the everyday annoyances I run into, like switching audio devices or adjusting monitor brightness.

    Everything here is made by one independent developer, Yuga Tanaka, and the source code is available on GitHub.

    Network use
    AudioSwitcher and Lumina connect to GitHub only to check for and download updates. Settings stay on your PC. MeatCam does not use the network.
    Code signing
    The apps are not code-signed, so Windows may show a SmartScreen warning the first time you run them. You can read the source code on GitHub first if you like.
