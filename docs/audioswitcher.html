AudioSwitcher

Switch your Windows audio output with one hotkey

OverviewFeaturesWhat's included

AudioSwitcher runs quietly in the background and switches your sound between speakers, a headset, an external DAC or any other output with a single global hotkey. No more opening the sound settings in the middle of a game or a call.

Three simple tabs

The window is split into three tabs: A/B Switch toggles between two devices, Multi-Device lets you pick from a list of your outputs (and choose which devices appear in it), and Settings holds the startup and update options.

A clear, compact notification

When you switch, a small card appears in the bottom-right corner with a headphone or speaker icon and the name of the new device, then fades away. It shows which device is active without covering your work, and also lets you know when an update is ready to install.

A built-in tutorial with animations

Click the ? button and the app walks you through each step with numbered captions, highlights and click animations. You can also open it from the Settings tab.

Handles devices with the same name

Windows often mixes up audio devices that share a product name. AudioSwitcher identifies each one by its unique ID from the Windows Core Audio API (via pycaw), so it always switches to the right device.

Starts with Windows

Turn on startup in the Settings tab and AudioSwitcher adds itself to the Windows startup folder. It works whether you run the Python script or the single .exe, so it's ready in the background every time you sign in.

English or Japanese

Choose the display language under Language in the Settings tab. The window switches instantly and keeps anything you haven't saved yet. English is the default.

What's included

  • AudioSwitcher.exe — The entire app, including device control. Nothing else to install.
About the Windows SmartScreen warning

AudioSwitcher isn't code-signed, so Windows may show a SmartScreen warning the first time you run it. Download and run it at your own risk. The full source code is on GitHub if you'd like to check it first.
